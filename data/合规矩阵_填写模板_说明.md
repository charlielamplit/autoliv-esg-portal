# 合规矩阵 · 数据填写模板说明

把调研结果填进下面两个 CSV，我据此替换看板里的「待核实」占位数据。两个文件用 **指标编码（metric_code）** 关联。

---

## 文件 1 — `matrix_cells.csv` （矩阵格子：每个"指标 × 客户"一行）

驱动 V2「要求矩阵」的每个彩色格子。**每个指标 × 每家有要求的 OEM 填一行**；某 OEM 对某指标无要求就不填（渲染为"—"）。

| 列 | 含义 | 取值 |
|---|---|---|
| `metric_code` | 指标编码 | 如 `ALV-E-001`（E=环境 S=社会 G=治理） |
| `metric_zh` / `metric_en` | 指标中/英文名 | 如 `碳中和目标` / `NetZero target` |
| `dimension` | 维度 | `E` / `S` / `G` |
| `oem` | 客户名 | 真实英文名，如 `Chery`、`NIO` |
| `status` | 该客户对该指标的状态 | `committed`（承诺达标·绿）/ `request`（请求·橙）/ `gap`（缺口·红） |
| `target_note` | 格子里的小字 | 如 `2045`、`−60% by 2030`、`60% RE` |
| `priority` | 优先级圆点 | `H` 高 / `M` 中 / `L` 低 |

## 文件 2 — `matrix_detail.csv` （展开行详情：每个指标一行）

驱动矩阵行"展开"后的详情面板。**每个指标编码填一行。**

| 列 | 含义 |
|---|---|
| `metric_code` | 与文件 1 对应的指标编码 |
| `clause_zh` / `clause_en` | 原始条款文本（中/英） |
| `source` | 条款出处（文件名 / 版本 / 条款号） |
| `owner` | Autoliv 内部负责人 / 部门 |
| `due` | 截止时间 |
| `evidence` | 证据附件状态（如 `SBTi 承诺函 ✓`、`I-REC 意向 · 缺失`） |
| `current` | Autoliv 当前值 |
| `target` | 目标值 |
| `suppliers` | 关联供应商，多个用 `;` 分隔（可含 Tier 说明，如 `SUP-0142;Tier-2 电子`） |

---

### 填写要点
- **编码规则**：`ALV-` + 维度(`E/S/G`) + 三位序号。同一指标在两个文件里编码必须一致。
- 状态只用 `committed / request / gap` 三种；空着不填＝该客户未提此要求。
- 中英文都填最好；只填中文我来补英文。
- 不确定的先留空，我保留"待核实"标记。
- 填好把两个 CSV 发我即可，我批量导入，无需你改看板。
