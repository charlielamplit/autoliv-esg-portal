逐条回答

Q1 · 三个"合规"
重复的是 V2/V4，不是三个合规
V4 的对象是客户要求（该并入"客户要求"域，与 V2 同页）；V6 的对象是法规义务；V8 的对象是法规事件。后两者同域不同时间尺度 → 合成 1 页 2 tab。结果：合规类一级栏目从 3 降到 1。
Q2 · 供应商 × 能力
合并，用视图切换
同一对象两套数据，不该是两页。建议"供应商"一级 + 顶部视图 tab（主数据 / 能力达标 / 分级 / 帮扶），共用一个供应商抽屉分 tab 展开。327 与 317 的口径在页头一次说清。
Q3 · 报告 / 尽调
都不该是一级
报告导出是全局动作 → 顶栏按钮 + 报告中心二级。新供应商尽调是供应商生命周期第 0 步 → 供应商清单页的「+ 新供应商」二级流程。一级栏目只放"工作对象"。
Q4 · 视角切换
移到顶栏用户区
切换的是身份而非页面，位置应与账号/语言/匿名开关同列。切换到"供应商 ABC56"后整个 shell 换成门户皮肤，返回按钮也在顶栏 —— 与"一个平台·四个角色"的叙事一致。
Q5 · 问卷与客户要求对齐
缺一页"传导对齐"
现在没有任何地方能看到"我问供应商的 10 题"从哪条客户要求推导而来。新增三列对齐页 + 在能力指挥舱每题旁标注来源条款（如 LCA ← 客户P SSI Q9 + 要求 #2 + CBAM），并在客户问卷 7c 的差距行提供「传导给供应商」动作闭环。
