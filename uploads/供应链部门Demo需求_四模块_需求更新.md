## 0. 附件解读（本次新增）

### 附件1 《2025 Autoliv Sustainable Sourcing Requirements — Direct Material Suppliers》（22页）

- **性质**：Autoliv 对直接材料供应商的可持续采购要求正式文件，引用 UNGC / 世界人权宣言 / ILO 宣言 / OECD 指南 / **Drive Sustainability GASGP**（与我们此前 OEM 调研的框架结论完全互证）；
- **结构**：**37 项要求/期望**，五大类——Climate & Circularity（#1-21：年度气候问卷、LCA、**PCF（ISO 14067 + Catena-X Rulebook，2025 新要求）**、IMDS 循环材料、SBTi 2028、净零 2040、全范围 GHG 追踪 2024、分材料路线图【钢-35% / 铝再生 75% / 镁再生 40% / 树脂-35% / 织物-35%】、绿电【2025≥30% / 2027≥60% / 2030=100%，供应链 100% 2030】、零毁林 2025）；Responsible Business（#22-27：CMRT/EMRT 年报、无制裁高风险冶炼厂、关键原材料年报、OECD 尽调）；Safe & Inclusive Workplace（#28-29：H&S 政策、申诉机制）；Saving More Lives（#30-32：道路安全）；Sustainability Framework（#33-37：高管责任、**向下传导 Autoliv 要求（#34，2024）**、按零件号供应链溯源 2025、年度自评、**Autoliv 现场审核权**）；
- **关键机制**：每项标注 **Requirement（不可谈判，作为长期合作最低门槛）vs Expectation（未来将转为强制）+ 生效年份 + 系统载体（Autoliv Partner Portal / IMDS / CMRT / CBAM declaration / GHG 申报 Excel）+ 工具链接**；履行状态反映在采购决策用的三个状态位（Climate & Environment / Conflict minerals / Social responsibility status），供应商在 Partner Portal 可见；
- **对 demo 的意义**：这就是 M1「AI 转译」的输入原文——37 项、双标记、多系统载体、英文长文档，正是中小供应商"看不懂、不知道先做哪个"的典型对象。且 #34 传导条款 + #37 审核权与我们全部既有叙事闭环。
- 注：条款细节页（p12-22 各项 Defined-as 全文）构建数据包时逐项提取，本稿仅用 p7 总表。

## M1 · 供应商侧作答体验：37 项要求 → AI 任务包 → 引导式完成

1. 输入附件1 → AI 解析 37 项为「供应商任务包」：每项 = Requirement/Expectation 徽章 + 生效年份 + 通俗解释（术语卡：PCF/IMDS/CMRT/SBTi）+ 需提交系统与证据 + 截止倒计时；
2. 供应商门户视角：不是 22 页英文 PDF，而是"你的 37 项：n 项已达标 / n 项今年到期 / n 项需准备"，逐项引导填报（含"为什么要这个 + 怎么准备 + 示例"）；年度气候问卷（要求#1）即任务包中第一项，作答体验对标 V7 7b（AI 预填 + 证据库 + 校验，含异常值拦截演示）；
3. 与 Autoliv 侧联动：供应商提交 → Autoliv 端三个状态位（Climate/Conflict minerals/Social）自动刷新——正好复刻其 Partner Portal 机制，客户会立刻认出。

## M2 · 供应链能力匹配 · 差距分析 · 帮扶服务（数据已齐，317 家真实统计）

一屏「供应链能力指挥舱」：
1. **顶部 KPI**（真算）：317 家 / $776M；全达标 107 家（38% 采购额）；高风险 47 家；未传导 67 家；
2. **能力热力**：10 题 × 达标率双口径（家数/采购额加权）柱状 + 高采购额×低能力四象限散点（Top20 中 11 家落入重点区，点名 ABC2/3/4/6/7…）；
3. **差距下钻**：点任一题 → 未达标供应商清单 → 每家差距明细；
4. **帮扶服务映射**（商务钩子，逐差距挂服务）：LCA 不会做（46% 缺口，最大）→ 培训进阶课程⑥ + LCA/PCF 代算；绿电为 0（67 家）→ 绿电绿证服务④；SBTi 未设（101 家）→ SBTi 辅导课程；数据填报异常 → 平台校验 + 因子查询⑦；未传导（67 家）→ 传导工具包（把 Autoliv 要求再打包下发，形成 Tier-N 级联）；
5. 输出：「帮扶优先级清单」（按采购额×缺口排序）+ 一页管理层摘要。

## M3 · 合规实时监控：MOFCOM 管制名单 → 供应链受影响分析（链主服务 II 实证）

**案例已核实（2026-06-29 商务部公告）**：禁止向 20 家日本实体出口两用物项（防卫研究所等 4 机构 + 三菱电机/三菱重工系 9 家 + 日钢特机等 7 家），含原产中国物项转移禁令，立即生效。

一屏「供应链安全监控墙」：左=政策流（商务部/BIS/EU 实时抓取 + AI 实体/物项抽取）；中=碰撞图谱（名单实体 ↔ 虚拟供应链主数据：演示两条链路——某二级供应商向三菱系供货的销售侧关联、某含中国原产两用物项出口件的转移禁令核查）；右=分级告警与处置（停止/核查/关注 + 指派留痕）。讲解口径："政策发布到告警分钟级；碰撞靠平台沉淀的供应链主数据——这就是数据放在平台上的价值"。受影响链路全虚构并标注。

## M4 · 新供应商引入尽职调查

引导流一屏：输入名称/信用代码 → 自动尽调（工商股权穿透 / 失信与环保处罚 / 制裁与管制名单筛查【与 M3 同引擎】/ ESG 基础问卷下发【M1 体验】/ CoC 签署）→ 红黄绿分级 + 准入建议 + 一键尽调报告。口径：传统 2-3 周 → 平台小时级初筛，人工只碰黄红项；对标行业实践（奇瑞十大红线）顺带展示专业度。
