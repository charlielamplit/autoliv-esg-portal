# Autoliv ESG Cockpit · 修复提示词（转 Claude Design）

> 用法：一条一条发给 Claude Design，做完在画布上点验，再发下一条。按优先级排序。
> 通用约定（每条都适用，不再重复）：全内联样式；双语 `.zh/.en`；`dc_*` 增量改、别整块重写；**按当前实现接进去，别按行号**；除本条目标外不动其它屏；mock 数据即可。

---

## P1-1 · 顶栏搜索：要么做成能用，要么别放假的

```
任务：顶栏那个"搜索客户、供应商、指标…"现在是个静态文字、点了没反应（死控件）。改成真能用的：
- 换成真 <input>，绑定一个 state（如 q）。
- 作用范围：过滤"当前视图的主列表"——在供应商清单(v3)就筛供应商、在全量要求(v13)就筛要求、在传导对齐(v12)就筛那几条、在客户问卷题目里就筛题。按名称/编号/关键字匹配即可。
- 输入为空时恢复全部；右侧加个清除✕。
- 若某视图没有可筛的主列表，输入框显示灰置"该视图暂不支持搜索"而不是假装能搜。
自检：① 是真输入框、能打字 ② 在 v3/v13/v12 打字能实时筛列表 ③ 清空恢复 ④ 双语占位。
```

## P1-2 · 大列表补筛选 + 可控排序（先做供应商清单）

```
任务：给"供应商清单"（供应商域·主数据清单 v3，327 行）补筛选和排序；这是最痛的长列表。
- 顶部筛选条：按 分级(A/B/C/D) · 类别(AB/SB/SW 或材料类) · 风险(高/中/低) · 达标区间。多选或单选皆可，点了实时筛。
- 列表支持可控排序：点"年供货额 / 达标数 / 评分"表头可升降序排（加个▲▼）。
- 顶部显示"筛选后 X / 327 家"。
- 同样的筛选+排序模式，随后也可用到 能力指挥舱(v7)的下钻列表与全量要求(v13)——本条先把 v3 做出来。
自检：① v3 顶部有筛选条、点了实时筛 ② 表头可排序、有升降序标记 ③ 显示"X/327" ④ 其它屏不受影响。
```

## P1-3 · 统一数据口径（数字词典 / 口径说明）

```
任务：全平台的数字对不上，用户会懵。建一处"口径说明"，把关键数字讲成勾稽链，并让关键 KPI 能查到定义。
- 在顶栏（帮助/ⓘ 图标）或总览里加一个「口径说明」入口，点开一个抽屉/面板，讲清三组：
  · 供应商：327 主数据 → 317 已回本年度气候问卷 → 本轮传导涉及 148（去重）。一句话说明每个数的范围。
  · 客户：14 家客户 → 6 家进要求矩阵 → 4 份问卷在办。
  · 要求：47 条客户要求 → 映射到 37 项 Autoliv 全量要求 / 112 道客户问卷题 / 8 项矩阵指标。
- 关键 KPI 数字（如 327 / 317 / 47 / 37）加一个小 ⓘ，hover 出一句口径定义。
自检：① 有「口径说明」入口、点开能看到三组勾稽链 ② 主要 KPI 有 ⓘ 口径提示 ③ 双语。
```

## P1-4 · 同一供应商跨屏贯通（一个平台一个用户）

```
任务：现在同一个供应商在 能力指挥舱(v7) / 供应商门户(v10) / 传导对齐(v12) 之间是各自的数据，串不起来。让它贯通。
- 在供应商详情抽屉（点 v3/v7 里某供应商打开的那个 abc/supplier 抽屉）底部加两个跳转：
  · 「查看该供应商门户视角 →」= 切到供应商角色(v10)并以该供应商身份展示（demo 可统一落到 ABC56 门户）。
  · 「它收到的下发 →」= 跳到传导对齐(v12)并高亮涉及该供应商的行（或弹出它收到的数据请求单）。
- 抽屉抬头统一显示该供应商的：编号 + 分级 + 采购额 + 达标画像，做到"一处点开、档案/达标/门户/下发全串起来"。
自检：① 供应商抽屉底部有"门户视角""收到的下发"两个跳转、点了能到对应屏 ② 抬头信息齐 ③ 其它屏不受影响。
```

## P1-5 · 导览模式（无讲解也能自助）

```
任务：加一个"导览/演示模式"，支撑用户没人讲解也能一步步走完主线。
- 顶栏加一个「▶ 导览」按钮。点开进入导览态：按金线剧本自动定位视图并浮一条说明条：
  第1步 导入(客户问卷 v11) → 第2步 响应/得分(v11) → 第3步 传导对齐(v12) → 第4步 供应商作答(v10) → 第5步 回流(触发 reflow，回到 v1/v7 看变化)。
- 每步说明条含：这一步在做什么(一句) + 「上一步 / 下一步」按钮 + 「退出导览」。
- 导览态下自动切到对应视图（复用现有 go 函数 / 角色切换）。
自检：① 顶栏有「▶ 导览」② 点了逐步走：每步自动到对应屏 + 有说明条 + 上/下一步可点 ③ 能退出 ④ 不破坏正常浏览。
```

```
- 报告类型里加/改为：① 客户问卷响应报告（取 v11 得分/差距）② 供应链传导进度报告（取 v12 回收/完成）③ 全量合规现状报告（取 v13）④ 回流更新说明（reflow 后的变化）。

自检：① 报告类型含上述四类 ② 选了能预览、数字来自对应屏 ③ 双语。
```
