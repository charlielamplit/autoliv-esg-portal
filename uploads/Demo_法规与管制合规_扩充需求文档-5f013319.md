## 0. 一句话背景 + v2 的核心调整

报告与汇报 PPT 同一论点：**法规正在把 ESG 从「年度报告」变成每一个零件/批次/供应商/工厂/交易的可验证属性**，缺口在「最后一公里」——能不能把收上来的数据**自动变成可交付结果**。因此本版把 V6/V8 从「法规图谱 + 监控墙」（看状态、看名单）**拧向「产出结果」**：

| v1（原）| v2（本版调整）|
|---|---|
| 每条法规展示 状态/影响/对供应商要求 | **+ 产出物 deliverable**：本项自动产出什么可交付结果（申报数据包/尽调记录/可审计证据）|
| AI 推荐动作（泛化）| **+ 挂载 Agent**：由 PPT 的 7 个 Agent 中哪个执行（规则解译/碳核算/报告生成…）|
| 法规→37 项 | **+ collectedBy 采集复用链**：证据由 ASSI 哪些题一次采集、多处复用（复现 PPT『一个问题满足多套要求』）|
| 分级 强/中/已排除；告警 停止/核查/关注 | **+ 状态色统一 🟢🟡🔴**：与 PPT 智能问卷同一套色标 |
| —（无）| **+ 适用性判定**：每条法规显式『为何适用于本供应商/本零件』（按国家/CN 编码/材料/角色）|
| V8 只监控名单 | **+ 产出 + 责任边界**：稀土/强迫劳动等产出台账/溯源包，并标『谁放行、谁独立核查』|

**状态色口径**（全 Demo 一套）：🟢 数据与证据齐全·可直接提交/已就绪 · 🟡 可暂用但需补验证·自动生成整改任务 · 🔴 重大缺口或高风险·触发采购/合规/现场审核升级。

## A2. reg 抽屉（结果导向版正文）

> 抽屉结构：抬头挂 影响★+紧迫+🟢🟡🔴 状态；**适用性判定**条（为何适用于本供应商/零件）；正文四栏 状态与核心要求/对 Autoliv 影响/对供应商要求/关键证据；**底部结果条**：自动产出 deliverable（由 X Agent）+ 采集自 collectedBy + 关联 37 项(跳 V13) + keyDates 倒计时。下给 C1/C2 全字段值。

### C1 · 气候·披露·尽调

**欧盟碳边境调节机制 CBAM**　`已有` · 🟢 · 影响 ★★★★★ · 紧迫 高 · 现状：已自评为重大转型风险；申报已嵌入供应商数据流

- 状态与核心要求：正式期自 2026-01-01；达门槛欧盟进口商/间接海关代表须成为授权申报人，申报清单内含商品嵌入排放并购买 CBAM 证书；覆盖水泥/钢铁/铝/化肥/电力/氢，是否适用取决于 CN 编码。
- 对 Autoliv 影响：进口钢/铝或清单内半成品时可能直接承担义务；普通安全系统成品不因含钢铝就被认定为 CBAM 商品，但材料成本与客户碳数据会间接传导。
- 对供应商要求：CN 编码、生产设施、生产路线、直接/间接排放、前体材料、碳价与验证所需底稿；数据须按批次/期间/工厂可追溯。
- **自动产出**：CBAM 申报数据包（嵌入排放+碳价+验证底稿，按 CN 编码/批次可追溯）　·　**执行**：碳核算 Agent + 报告生成 Agent
- **采集复用**：ASSI 第 #9、#10、#11、#12、#13、#16、#18、#19 等 题（共 20 题，一次采集多处复用）
- 关键日期：2026-01-01 正式期 · 2026-03-31 授权申报人申请截止 · 2027-09-30 首次年度申报

**CSRD / ESRS（企业可持续报告指令）**　`新增` · 🟢 · 影响 ★★★★☆ · 紧迫 中 · 现状：双重重要性评估已完成并对齐 CSRD

- 状态与核心要求：2026 修订后一般门槛为平均员工>1,000 且净营业额>4.5 亿欧元；第三方集团触发门槛提高；须按双重重要性披露并接受鉴证。
- 对 Autoliv 影响：集团规模较大，须按具体欧盟法人/第三方集团结构确认范围；即使个别实体退出法定范围，OEM 与资本市场仍可能要求近似 ESRS 数据。
- 对供应商要求：价值链排放、水、污染、资源循环、生物多样性、劳工、人权和商业道德数据；统一口径、期间、边界、估算方法和证据。
- **自动产出**：ESRS 口径价值链数据集 + 双重重要性披露底稿　·　**执行**：报告生成 Agent
- **采集复用**：ASSI 第 #9、#10、#11、#12、#13、#16、#18、#19 等 题（共 18 题，一次采集多处复用）
- 关键日期：2027-01-01 新范围财年起点

| 样品、维修件、设备和备件 | 非量产物料容易绕过常规订单流程 | 把免费样品、退换货、维修、模具、设备备件纳入同一审批 |
| 软件、图纸、工艺或远程支持 | 受控技术/数据可能通过邮件、云盘或远程服务提供 | 技术分类、访问控制、下载日志、人员和国家权限；不得只管实物 |
| 供应商代发或三角贸易 | Autoliv 看不到实际物流或最终用户 | 合同要求供应商提供路线、承运人、收货人和最终用户；保留审计权 |
| 与日本大型集团的交易 | 名单内实体名称可能与集团内其他法人相近 | 按「精确法人+地址+别名+所有权/控制关系」审查，既避免漏筛也避免误伤非名单法人 |

## B6. 告警分级 + 一票否决

告警在 停止/核查/关注 之上置顶 🔴 **红旗/一票否决**（对应报告 8.1 七条 + KPI『名单/红旗交易未审批放行=0』）：

- ✗ 命中出口管制/制裁名单且无合法许可
- ✗ 故意伪造 PCF、绿电、原产地、再生含量、矿产或审计证据
- ✗ 拒绝提供最终用户、Tier-N、审计或纠正措施信息
- ✗ 重大安全事故或环境违法后未立即控制和报告
- ✗ 使用童工、强迫劳动或扣押证件等重大人权问题
- ✗ 含禁止物质或未履行重大化学品合规要求
- ✗ 发现受制裁/高风险冶炼厂后拒绝移除或缓解

## B7. 责任边界（第 12 页 → V8 高风险项显式标注）
